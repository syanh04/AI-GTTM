# Frontend — Smart Traffic AI

Dashboard Next.js cho giám sát camera, đối soát kết quả AI, quản lý hồ sơ vi phạm và báo cáo vận hành.

## Cài đặt và chạy

```powershell
cd frontend
npm ci
npm run dev
```

Mở `http://localhost:3000`. Backend cần chạy song song tại `http://127.0.0.1:8000`.

## Các lệnh hữu ích

```powershell
npm run dev      # Chạy môi trường phát triển
npm run lint     # Kiểm tra lint
npm run build    # Tạo production build
npm run start    # Chạy production build
```

## Điều hướng chính

- Giám sát camera và lưới camera động
- Trung tâm phân tích và báo cáo thống kê
- Hồ sơ vi phạm và lịch sử xử lý
- Cấu hình AI, camera, thiết bị và người dùng
- Trợ lý AI
